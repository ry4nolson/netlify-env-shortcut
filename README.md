# Netlify Env Vars Shortcut

A Chrome extension that adds an **Env vars** link directly to the Netlify project nav, so you don't have to dig through Project configuration every time.

## Installation

Chrome does not require the Web Store for this — you can load it directly in a few steps.

### 1. Download the extension

Clone the repo or download it as a zip:

**Option A — Clone**
```
git clone https://github.com/ry4nolson/netlify-env-shortcut.git
```

**Option B — Download zip**

Click **Code → Download ZIP** on this page, then unzip it somewhere permanent (don't leave it in Downloads).

### 2. Load it in Chrome

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** using the toggle in the top-right corner
3. Click **Load unpacked**
4. Select the `netlify-env-shortcut` folder

The extension is now installed. You'll see it listed on the extensions page.

### 3. Use it

Navigate to any project on [app.netlify.com](https://app.netlify.com) and the **Env vars** link will appear in the left nav directly below **Project configuration**.
